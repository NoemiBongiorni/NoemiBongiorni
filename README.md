- [**Statistical Learning for ICU Mortality Prediction**]([link al repo ICU]): pipeline on 2,520 ICU records with mRMR feature selection, soft-voting ensemble and SHAP interpretability

- [**Mars Terrain Segmentation**](https://github.com/NoemiBongiorni/Segmentation-for-terrain-images): Dual UNet for 5-class image segmentation (Kaggle score 64.91%)
- [**Inferential Statistics for Body Fat**](https://github.com/NoemiBongiorni/Inferential-Statistics-for-body-fat): inference, linear regression and ANOVA, with cross-validation (R)
- [**Blood Cell Classification**](https://github.com/NoemiBongiorni/NN-for-blood-cells-classification): neural networks for image classification
